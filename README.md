# AL ARAB AL MASI — EXECUTIVE GROWTH OS

الوكيل الإداري والتنفيذي وغرفة العمليات لمنظومة **العرب الماسي | Al Arab Al Masi** (`https://alarabalmasi.com/`) وفروعها الأرضية الثلاثة المستقلة في جدة.

## المعمارية والوحدات المفعّلة

- **`src/config/identity.ts`**: الهوية الرسمية الموثقة من المتجر (السجل التجاري `4030113177`، الضريبي `312669206500003`، العلامة `TM-01-00-34943-26`، الفروع الثلاثة وأرقام واتسابها، السياسات المنشورة، وروابط مراجع Google Workspace).
- **`src/connectors/sheets-live.ts`**: قراءة حية (Read-Only) من لوحة المتابعة التنفيذية في Google Sheets (`1GtRjDlzEBy62EOjMBV9Zeyuj5vS-aR_hxlPtK2M_e1w`) عبر `gsheets` CLI مع حفظ لقطة في `data/live-snapshot.json`.
- **`src/core/executive-advisor.ts` & `src/core/charter.ts`**: العقل التنفيذي وموجّه الـ 22 تخصصاً (يُخرج القرار أولاً ثم الأدلة وخاتمة القسم 22 باللهجة السعودية النجدية الاحترافية، مع دعم اختياري لمحرك LLM عبر `.env`).
- **`src/core/profitability.ts`**: حاسبة الربحية والمؤشرات (CVR, AOV, CPA, CAC, ROAS, CTR, هامش المساهمة قبل/بعد الإعلان، Break-even ROAS) بقاعدة صارمة: البيانات الناقصة تبقى `null` ولا تُعامل كصفر أبداً.
- **`src/core/abandoned-carts.ts` & `src/connectors/zid-carts.ts`**: مهارة السلات المتروكة (القسم 17) — تصفية صارمة على `created_at` بتوقيت الرياض، استبعاد من أتم الطلب، صياغة رسائل سعودية طبيعية وروابط `wa.me` مع قفل الإرسال التلقائي دون موافقة.
- **`src/core/product-writer.ts`**: محرك كتابة صفحات المنتجات الهجين (القسم 10: SEO/GEO/CRO، جدول مواصفات صادق، FAQ، 5 عبارات بحث شرائية، ALT عربي/إنجليزي، أسماء WebP 1000×1000، وJSON-LD `Product`).
- **`src/core/quality-gate.ts`**: بوابة الجودة من 60 زاوية تخصصية (12 مجالاً × 5 نقاط) + معايير الإتقان التنفيذي العشرة (لا تمنح `ناجح` بدون دليل).
- **`src/server/index.ts` & `src/web/`**: غرفة العمليات التنفيذية الكاملة بواجهة ويب عربية RTL.
- **`skill/`**: المهارة الدائمة (`alarab-almasi-executive-os`) المثبّتة داخل Antigravity مع ملف الحقائق الموثقة.

## أوامر التشغيل (Node.js 22.6+ بدون اعتمادات خارجية)

```bash
# تشغيل الاختبارات (10 اختبارات تغطي الربحية والسلات وبوابة 60 زاوية وكاتب المنتجات)
npm test

# سحب لقطة حية من لوحة المتابعة في Google Sheets
npm run snapshot

# تشغيل الموجز التنفيذي من سطر الأوامر
npm run exec:brief

# سؤال الوكيل الإداري مباشرة من سطر الأوامر
npm run exec -- ask "قيّم وضع الإعلانات وROAS وهل نرفع الميزانية؟"

# فحص حالة الأدوات المتصلة في البيئة
npm run exec -- tools

# تشغيل غرفة العمليات التنفيذية على الويب (http://localhost:4090)
npm start
```
